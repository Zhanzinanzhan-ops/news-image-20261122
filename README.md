The image is drawn by `generate.py` from the researched headlines in `news.json` (sources: AP, Reuters, BBC, The Times, Daily Perspective), with real fonts so every word is exact.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

That writes the image to `out/entry.png` (1024x1024 PNG, under 1 MiB, identical bytes on every run).
